01 — Tjenester

Hva vi gjør

Utvikling av fremragende løsninger basert på Microsoft og .NET-teknologi, etter gjeldende best-practice.

  • 01WebløsningerHTML, CSS og JavaScript på ledende rammeverk som Angular og React.
  • 02MobilløsningerMobil først, og ekte apper for iOS og Android med Xamarin eller React Native.
  • 03SkytjenesterVi løfter løsninger opp i skyen med Microsoft Azure.
  • 04API og .NETForretningslogikk eksponert som REST-API-er på .NET.
02 — Ambisjon

Web skal bli et bedre sted

Hver eneste dag skriver vi HTML, CSS og JavaScript basert på de siste, ledende rammeverkene. Ambisjonen og lidenskapen er å gjøre webben til et bedre sted.

  • Mobil først – når vi utvikler web.
  • Best-practice – etter gjeldende standard.
  • Azure – sky når det passer.
