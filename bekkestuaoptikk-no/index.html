Om BEKKESTUA OPTIKK

Øynene dine er like individuelle som ditt DNA. Det ser DNEye Scanneren.

Tørre øyne er et svært vanlig og plagsomt fenomen. Flere av tegnene på tørre øyne kan forveksles med andre problemer, og dermed gå ubehandlet.

Barn som ser dårlig vet sjelden selv at de kan se bedre. Barnets syn henger også sammen med den motoriske utviklingen, og dårlig syn kan virke hemmende på lek og læring.

Mer om det vi gjør

Vi har fokus på kompetanse, behovsanalyser og tilrettelagt kundeservice under alle våre synsundersøkelser. Med 60 års erfaring i bransjen, kan vi tilby kunnskap og erfaring som tar vare på ditt syn.

Vi tilbyr synstrening for både voksne og barn. Behandlingen passer for de som ønsker å styrke sin øyemuskelatur og som opplever samsynsproblemer.
