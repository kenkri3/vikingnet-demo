Om GET Academy

En fagskole i Larvik for folk som vil lære å kode — og for bedrifter som trenger folk som kan det.

Hvorfor vi finnes

KI erstatter ikke lagarbeid

Selv om KI kan mye, vil det være behov for folk som kan kode, tenke logisk og løse komplekse problemer sammen med andre. Vi utdanner folk som kan ta ansvar for helheten, ikke bare skrive linjer.

Vi holder til på Torget 3 i Larvik, og samarbeider med bedrifter om prosjekter og praksis.

  • Utdanning i frontend og programmering
