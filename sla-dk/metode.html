Metode

Naturbasert design handler ikke om å plante mer. Det handler om å lese stedet først, og velge løsninger som holder uten konstant stell.

01

Les stedet

Jord, vann, vind, solforhold og hvilke arter som faktisk trives der. Vi kartlegger før vi tegner.

02

Velg det som vedlikeholder seg selv

Løsninger som naturen driver videre, krever mindre drift og tåler mer.

03

Test mot bruk

Folk, årstider og drift er testen. Det som ikke fungerer i november, fungerer ikke.

04

Følg opp

Vi blir med etter åpning, for å se hva som vokser som planlagt — og hva som må justeres.

Hvorfor det betyr noe

Grønt som tåler tid

Mye grønt i bygg og byrom blir kostbart fordi det ikke passer stedet. Når artene og forholdene stemmer, blir anlegget både billigere å drifte og bedre å bruke.

  • Arter tilpasset stedet
  • Vann som håndteres der det faller
  • Materialer med lang levetid
