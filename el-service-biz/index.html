Om EL-SERVICE DIN EL OG IT INSTALLATØR

El-Service Din El og IT Installatør AS er en lokal elektroentreprenør med base i Sandefjord og oppdrag i Tønsberg, Larvik, Horten, Holmestrand og Stokke.

Vi legger stor vekt på punktlighet, ryddig dialog på byggeplassen og løsninger som gir kundene våre lavere energibruk og trygg drift i mange år fremover.
