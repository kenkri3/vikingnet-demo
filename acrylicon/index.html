Seks systemer til

  • TankCoating System — vertikale og horisontale flater, ca. 2 timer herdetid, 0,4–1,5 mm.
  • Variant Paint System — maling med gulvegenskaper, forsegling for betong, 0,5 mm.
  • Composite Terrazzo System — dekorativ overflate, 8 mm, 75 % raskere installasjon enn tradisjonell terrazzo.
  • Multigrip — elastisk, værbestandig og sklisikkert, for parkering, gangveier og ramper.
  • Laquer System — reaktivt MMA-basert, hard og slitesterk forsegling på betong og murgulv.
  • Levelling Screed — løsemiddelfri utjevning, 5–25 mm som standard, avretting opptil 550 mm.
