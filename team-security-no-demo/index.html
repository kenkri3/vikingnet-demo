02 — Slik jobber vi

Utstyr som passer bygget

Vi begynner med befaring: hvor er inngangene, hva skal overvåkes, og hvordan bruker dere bygget. Deretter setter vi sammen alarm, kamera og adgangskontroll som henger sammen.

  • Befaring – før vi anbefaler noe.
  • Installasjon – gjort ferdig.
  • Oppfølging – når noe skjer.
