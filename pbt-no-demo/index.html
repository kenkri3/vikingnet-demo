Om oss

Slik jobber vi

Dette skaper vi ved å levere kvalitet i alle ledd og å gi deg tett oppfølging gjennom hele prosessen.

Gjennom våre verdier åpenhet, tilstedeværelse og kvalitet, skal vi ta vare på våre kunder i mange år fremover.

Bærekraft og miljø er derfor en viktig del av vår drift og strategi.

Vi er sertifisert Miljøfyrtårn-bedrift og på våre eiendommer tilbyr vi blant annet EOS-systemer og grønne bygg.

Slik beskriver de det selv

Det norske klimaet kan by på utfordringer vinterstid, enten det er snakk om glatte og isdekte veier eller områder som må måkes for snø. Både næring, sameier, borettslag, offentlig sektor og private kan ha behov for vintertjenester som salting og snørydding.

Vedlikehold av grøntområder tilhørende næring, offentlig sektor, sameier, borettslag eller private kan være tidkrevende, og spesielt dersom det er snakk om større områder.

Teknisk forvaltning er en tjeneste som omfatter vedlikehold og drift av eiendommer. Det kan være snakk om både inn- og utvendige tjenester, der formålet er å ivareta bygninger og driften av disse.
