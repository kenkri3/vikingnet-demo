  • Om SET Elektro

    SET Elektro AS er et privateid selskap som spesialiserer seg på elektrotjenester innen samferdsel og installasjon. Vi er ca 100 dyktige medarbeidere som hver dag jobber for belyse og sikre veier rundt om i landet.

    SET Elektro er NS-EN ISO 9001:2015-sertifisert , noe som sikrer at vi jobber etter strenge kvalitetsstandarder. Vi bruker Kvalitetskontroll, som gir effektiv håndtering av sjekklister, vernerunder og avviksmeldinger via smarttelefon, nettbrett og PC.

Om SET ELEKTRO

Vi vokser og er stadig på utkikk etter dyktige medarbeidere! ‍ Lyst til å jobbe hos en av bransjens mest spennende aktører?

SET Elektro har ansatte fordelt på øst, vest, sør og nord- Norge. Vi har et stort fokus på et godt arbeidsmiljø og våre ansatte er vår viktigste eierandel.

SET Elektro har solid kompetanse innen installasjon, styring, regulering og overvåkning – og leverer tjenester til stat, kommune, næringsliv og industri. Vi utfører alt fra mindre rehabiliteringsoppdrag til komplekse el-anlegg, og tilbyr løsninger innen brann, nødlys, tele- og datainstallasjoner.

Mer om det vi gjør

SET Elektro er totalleverandør innen internkontroll. Vi utfører elektrotermografi, el-kontroll, brann-kontroll og nød/ledelys kontroll.
