02 / Om oss

Vi lyser opp og sikrer veiene.

SET Elektro AS er et privateid selskap. Vår kundeportefølje består i hovedsak av offentlige aktører og større entreprenører, hvor vi leverer pålitelige og kvalitetsmessige løsninger.

Sikkerhet, kvalitet og bærekraft er ikke ord vi bruker fordi de klinger godt — de er kriteriene vi blir målt på ute på anleggene.
