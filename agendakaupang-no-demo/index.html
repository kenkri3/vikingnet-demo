01 — Tjenesteområder

Det vi jobber med

Vi jobber på tvers av ledelse, styring, økonomi og digitalisering – og setter sammen team etter oppdragets behov.

  • 01Strategi og styringMål, prioriteringer og styringssystemer som faktisk brukes i hverdagen.
  • 02Økonomi og effektiviseringØkonomistyring, analyser og tiltak som gir bedre ressursbruk.
  • 03Omstilling og organiseringOrganisering, bemanning og gjennomføring av endringer.
  • 04Ledelse og medarbeiderskapLederutvikling, mellomlederprogram og barnevernledelse.
  • 05Evaluering og utredningFølgeforskning, evalueringer og utredninger med tydelige funn.
  • 06Digital forvaltningsutviklingDigitalisering som henger sammen med styring og arbeidsprosesser.

03 — Slik jobber vi

Fra spørsmål til funn

Vi starter med spørsmålet oppdragsgiver faktisk trenger svar på, ikke med metoden. Deretter velger vi datagrunnlag og analyser som kan belyse det – og leverer funn som er til å handle etter.

  • Kartlegging – dokumenter, data og intervjuer.
  • Analyse – mønstre som holder når de blir prøvd.
  • Formidling – rapporter og presentasjoner som blir lest.
