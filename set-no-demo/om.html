Om SET Elektro

En elektroentreprenør som jobber over hele landet.

Kvalitet, sikkerhet og bærekraft

SET Elektro AS er en elektroentreprenør. Vi tar oppdrag over hele Norge, og jobber etter tre kjerneverdier: kvalitet, sikkerhet og bærekraft i alt vi gjør.

Vi tar oss av både prosjekter og løpende drift – og har egne sider for nyheter og karriere.
