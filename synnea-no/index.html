Om Synnea Technologies

Synnea turns the spreadsheet interface register into a connected model you can actually query — trace what depends on what, see what a failure takes down, and prove every safety-critical signal is redundant. Free forever for your first vessel.

The interface register is a spreadsheet no one fully trusts — one tab per vendor, “_final_v7” , and no one can say what trips when Generator A goes down.

Systems and their directional interfaces — protocol, criticality, redundancy — in one model per installation. Import the lists you already have; refine inline.

Dette gjør vi

  • A living interface register

    Systems and their directional interfaces — protocol, criticality, redundancy — in one model per installation. Import the lists you already have; refine inline.

  • A graph, never a hairball

    Start at one system and expand outward on demand. Semantic zoom, domain lenses, and dependency tracing keep a 500-system vessel legible.

  • What breaks if it fails

    Pick a system and see everything that depends on it — direct and indirect, every hop, ranked by criticality. Fault analysis and change planning in one view.

  • Redundancy you can prove

    Synnea surfaces single-fed safety-critical paths — the missing third gyro, the un-doubled signal — before a class surveyor finds them. Collaborate

  • Owner, yard & vendor, one register

    Share an installation in full, or scope a vendor to just their systems — counterparts stay redacted. Everyone works the same register at the role you grant them, from editor down to read-only class access.

  • Completeness at a glance

    A source × target matrix shows every connection — and every gap — across the installation, coloured by criticality. Spot what’s missing in seconds.
